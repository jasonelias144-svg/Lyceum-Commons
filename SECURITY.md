# Security policy

## Reporting a vulnerability

**Don't open a public issue for a security problem.** Use GitHub's private
reporting instead: on the affected repository, open the **Security** tab and
choose **Report a vulnerability**. Only the owner sees the report.

Please include what is affected, how to reproduce it, and what an attacker
could do with it. If you found an exposed key or token, say where; don't copy
it into the report.

## What happens next

- The report is acknowledged at the next working session, normally within a few days.
- Anything causing harm now is handled as an incident: stop the harm first,
  then fix it properly
  ([handbook P7](https://github.com/jasonelias144-svg/policy-handbook/blob/main/protocols/P7-incidents.md)).
- Fixes go through the normal review. The reporter is credited, unless they
  would rather not be.

## Scope

The `main` branch of every active project listed in the
[registry](https://github.com/jasonelias144-svg/policy-handbook/blob/main/REGISTRY.md).
