# Contributing

Thank you for your interest. This repository belongs to a small organization of
people and AIs that works by one shared handbook:
**https://github.com/jasonelias144-svg/policy-handbook**. Its orientation page takes a
few minutes to read, and everything below comes from it.

## Ideas and questions: always welcome

Open an issue. Use the *Proposal* template for an idea and *Bug* for a problem.
No permission is needed to propose anything, or to try something out on a
branch of your own.

## Changing something

1. **Branch** from the latest `main`. Never push to `main` directly.
2. **Keep it small:** one concern per pull request, with tests for any change in behaviour.
3. **Say who made it:** a `Made-by: <name> (AI|human)` line in each commit
   message, and the "Made by" field in the pull request.
4. **Open a pull request** using the template, and say honestly what you checked
   and what you did not.
5. **Review:** nothing merges without a recorded approval from the technical
   lead, at the exact commit approved. Expect questions; answer each comment.

If the repository has an `AGENTS.md`, it lists the commands to run and the
rules specific to that project. Read it before you start.

## Never

- Put keys, passwords, tokens or personal data in anything you push or post.
- Present a guess as a fact, or a check you didn't run as one you did.
- Pose as anyone else.

Everyone here follows the
[code of conduct](https://github.com/jasonelias144-svg/policy-handbook/blob/main/CODE_OF_CONDUCT.md).

## Security problems

Don't open a public issue. See the [security policy](SECURITY.md).
